VS Code Git 가이드

초보자를 위한 단계별 가이드

01 브랜치 만들기 & 전환

  1. 왼쪽 하단 브랜치 이름 클릭 (예: main)
  2. + Create new branch 클릭
  3. 브랜치 이름 입력 후 Enter
  4. 다른 브랜치로 전환하려면 같은 곳에서 이름 클릭
# 브랜치 만들고 바로 이동 git checkout -b 브랜치이름 # 기존 브랜치로 전환 git checkout main

02 커밋 & 푸시

  1. Ctrl + Shift + G → 소스 제어 열기
  2. 변경 파일 옆 + 클릭 → Staged Changes로 이동
  3. 상단 메시지 입력란에 커밋 메시지 작성
  4. Ctrl + Enter → 커밋 완료
  5. 상단 ··· 메뉴 → Push 클릭
git add . git commit -m "커밋 메시지" git push origin 브랜치이름

03 충돌(Conflict) 해결

  1. Ctrl + Shift + G → Changes에서 C 표시 파일 클릭
  2. 충돌 파일이 열리면 아래와 같은 마커 확인
  3. 충돌 부분 위 버튼 중 하나 선택
  4. 저장 후 커밋
<<<<<<< HEAD
내 로컬 변경 내용
=======
원격(상대방) 변경 내용
>>>>>>> origin/main
Accept Current Change 내 것 유지

Accept Incoming Change 상대방 것 선택

Accept Both Changes 둘 다 합치기
# 충돌 해결 후 git add . git rebase --continue git push origin main
💡 pull 충돌이면 git merge --continue, rebase 충돌이면 git rebase --continue

04 체리픽 (Cherry-pick)

  1. 가져올 커밋 해시 확인 (Ctrl + Shift + P → git log)
  2. main 브랜치로 이동
  3. 터미널에서 cherry-pick 실행
  4. 충돌 나면 해결 후 git cherry-pick --continue
git checkout main git cherry-pick 커밋해시 # 충돌 시 git add . git cherry-pick --continue git push origin main
💡 커밋 해시는 git log --oneline 으로 확인

05 Pull & Fetch

  1. 소스 제어 ··· 메뉴 → Pull 또는 Fetch
  2. 또는 왼쪽 하단 새로고침 아이콘 클릭
# 가져오면서 바로 합치기 git pull origin main # 깔끔하게 rebase로 합치기 git pull --rebase origin main # 확인만 하고 합치지 않기 git fetch origin
💡 pull = fetch + merge / pull --rebase = fetch + rebase
